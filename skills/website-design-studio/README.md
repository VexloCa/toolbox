# Website Design Studio

> Plan, write, and review a website that actually converts

**Category:** Marketing & Content · **Difficulty:** Light setup · **Works with:** Claude, ChatGPT, Claude Code

## The problem

Most small-business websites were written in an afternoon, lead with "Welcome to our website," and haven't been seriously reviewed since launch. Hiring an agency costs thousands; DIY advice online is contradictory; and generic AI prompts produce copy that reads fine but converts nobody because it isn't built around one clear visitor action.

## The skill

The installable file is [`SKILL.md`](SKILL.md) in this folder. Four ways to use it:

- **One command (Claude Code, Cursor, Codex and other agents):** `npx skills add VexloCa/toolbox --skill website-design-studio`
- **Claude apps, any plan including Free:** zip this folder, then in Claude open Customize > Skills, click +, choose Create skill, then Upload a skill. Code execution has to be on (Settings > Capabilities). Claude then loads it when a request matches.
- **Claude Code:** copy the folder to `~/.claude/skills/website-design-studio/`, or to `.claude/skills/` inside a project.
- **ChatGPT, Gemini, or Copilot:** paste the contents of `SKILL.md` at the start of a conversation or into a project's instructions.

## How to use it

1. Click "Install skill" on this page and copy the install prompt.
2. Paste it into your AI assistant (Claude, ChatGPT, Cursor. Anything that can fetch a URL or accept pasted text).
3. Answer the skill's setup questions about your business.
4. Paste your current homepage text for a section-by-section review first. The "Top 3 changes by impact" list tells you where to start before rewriting anything else.

## Example

A physiotherapy clinic pastes its homepage. Output (condensed): Hero: Fix: "Welcome to Lakeside Physio" says nothing; rewrite: "Get moving again: usually within 3 visits. Direct billing, evenings available." Services grid (Keep, but move above the team bios. Team bios) Fix: lead with credentials patients care about, cut the third paragraph of each. "Our philosophy" section (Cut: it delays the booking ask and repeats the hero. Footer) Fix: phone number must be a tap-to-call link on mobile. Top 3 changes: rewrite hero with outcome and booking button; move Google reviews (4.9, 212 reviews) directly under the hero; reduce to one CTA ("Book an assessment"), repeated three times down the page.

## Pro tip

Give it your top competitor's homepage text too. Asking "what does their page do better and worse than mine?" produces the sharpest review of all, because the skill can position your copy against what visitors are actually comparing you to.
